## Задания

### Задание 1 — Игра «Гоблин» (обязательное)

Игра в стиле «Whack-a-mole»:
- Гоблин появляется случайно в одной из 9 клеток на 1 секунду
- Клик по гоблину — +1 очко
- Пропустил 5 появлений — игра окончена
- Код разбит на классы: `Game`, `Field`, `Goblin`

### Задание 2 — TOP Менеджер задач (опциональное)

- Добавление задач по нажатию Enter
- Ошибка при пустом поле (без alert)
- Закрепление/открепление задач
- Фильтрация по началу названия (регистронезависимо)
- Данные хранятся в массиве объектов `Task`

### Задание 3 — Галерея изображений (опциональное)

- Добавление по кнопке или Enter
- Валидация URL через `img.onload` / `img.onerror`
- Ошибка при неверном URL (без alert)
- Удаление изображений
